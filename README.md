# SOQT Labs

Company site for SOQT Labs — a software products studio.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

1. Push this repository to GitHub (`soqt-labs/soqt-labs`).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.

The site will be available at `https://soqt-labs.github.io/soqt-labs/`.

No build step or Actions workflow is required for this static HTML/CSS site.
